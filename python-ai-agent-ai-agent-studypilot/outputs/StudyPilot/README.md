# StudyPilot 📚

一个逐步构建的开源教育 AI Agent 项目。**当前发布 v0.6.0：AI 改用免费国产模型（主 GLM-4.7-Flash，备用 Xing4.0-29B）。** 保留本地 Streamlit 版、Vercel Web 入口、PostgreSQL 云端持久化、账号隔离、规则排课、亮色／深色和只读查询、修改提案与用户确认执行。

部署到 Vercel 请先看 [DEPLOYMENT.md](DEPLOYMENT.md)：根目录为 python-ai-agent-ai-agent-studypilot/outputs/StudyPilot，使用 FastAPI 入口与 PostgreSQL。原 app.py 是本地 Streamlit 界面，不是 Vercel 函数入口。云端不会自动上传或迁移本地账号数据。

v0.1.1 重新设计了界面：参考 [Offmap](https://www.offmap-x.ai/) 的大标题与分区思路，采用暖白纸张底色、珊瑚色重点、横向导航和原创 SVG 学习插画。首页新增可用学习日展示，以及直接进入任务和档案的快捷按钮。原来的 SQLite 数据无需迁移，读写确认逻辑保留。字体和图片均使用本地资源，不依赖外部字体服务。

适合每周只有少量学习时间的学生。默认档案草稿为每周 8 小时，周五 120 分钟、周六和周日各 180 分钟，周五至周日可用电脑。默认值可修改，不会自动保存为真实档案；数据库没有示例任务或虚构学习记录。

2026-10-16 界面更新：圆角导航与选中胶囊、按钮悬停和按压回弹、学习日卡片错峰入场、插画悬停摆动、输入聚焦高亮、下拉菜单与折叠内容入场。动画使用本地 CSS，遵循系统“减少动态效果”设置，触屏不启用悬停位移动画。

## 已实现与边界

- 中文 Streamlit 界面：学习概览、学习档案、学习任务、学习计划、学习记录、账号设置、AI 助手。
- 本地注册、登录、退出、修改密码、恢复码重置密码；每个账号独立档案与学习数据，开发者角色控制开发进度入口。
- 个人资料：昵称、内置头像标识、个性签名；登录用户名可在验证当前密码后修改，账号 ID、学习数据和角色保留，其他会话退出。昵称不影响登录名。
- 登录会话列表、退出其他会话、导出自己的学习数据为 JSON；不导出密码、恢复码、令牌及其摘要。
- 学习档案：目标、各科目基础与优先级、速度、偏好、每天可用时间与设备。
- 任务创建、编辑、删除、截止日期、预计分钟、完成状态和电脑需求。
- 按日期记录真实学习分钟，查看每周历史；误记后可确认删除并重录。
- SQLite 首次自动建表，重启保留数据；每次写入学习数据前必须勾选确认并点击提交。
- 输入校验、参数化 SQL、事务、任务和档案版本检查，以及任务变更历史。
- 基础图表：实际学习分钟、科目投入比例、每周学习历史。
- 规则排课：扣除本周真实用时后按每周预算、每日容量、电脑条件、截止日期和优先级安排任务，按单次时长上限拆分，无法安排的部分说明原因。预览不写计划，明确确认后保存或替换；重启后可读取。

- AI 助手：通过免费国产模型（智谱 GLM-4.7-Flash，限流或超时改用硅基流动 Xing4.0-29B）查询当前账号的真实资料、任务、记录和进度；修改先保存待确认提案，显示完整内容或前后差异，用户勾选确认并点击执行后才写入业务数据。模型没有确认执行、SQL、文件、网络或账号权限工具。

**尚未实现**：考试优先级自动调整、目标里程碑完成率、无人值守自动执行。每天档案只提供可用分钟，不包含具体钟点，因此规则计划展示日期与分钟段；手工任务创建本身不修改计划。未配置 API Key 时所有本地功能继续可用，AI 联网对话不可用。

## Windows 安装与运行

需要 Python 3.11+、Windows 10/11；本次验证环境详见 [验证记录](VALIDATION.md)。首次安装依赖需要网络，安装后核心功能可离线使用。

**双击启动**：双击项目中的 `Start-StudyPilot.cmd`，它会启动本地网站并优先用 Google Chrome 打开 [http://127.0.0.1:8501/](http://127.0.0.1:8501/)。保持服务窗口打开，按 `Ctrl+C` 停止；下次使用再双击即可。已经运行时会直接打开现有服务。8501 端口应专用于 StudyPilot，不要同时运行另一个 Streamlit 应用。

启动入口优先使用项目 `.venv`；在当前开发工作区可复用已安装的 `work\.venv`。解压到其它位置首次启动时，会使用已安装的 Python 创建 `.venv` 并联网安装依赖，不会安装 Python 本身。仍可按下方步骤手动安装。此网址仅在这台电脑上、服务运行期间可用，无需公网部署。

解压或克隆项目。在 PowerShell 中进入包含 `app.py` 的 StudyPilot 目录：

```powershell
cd "C:\你的目录\StudyPilot"
py --version
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-local.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

这里直接调用虚拟环境里的 Python，不需要执行 `Activate.ps1`，也不用修改 PowerShell 执行策略。若没有 `py` 命令，安装 Python 并选择添加到 PATH，或使用可用的 `python` 命令替代前两行的 `py`。

浏览器打开 [http://localhost:8501](http://localhost:8501)。停止服务：在运行窗口按 `Ctrl+C`。

第二次启动只需要：

```powershell
cd "C:\你的目录\StudyPilot"
.\.venv\Scripts\python.exe -m streamlit run app.py
```

默认账号数据库为 `data\accounts\accounts.db`；每个账号的学习数据保存在 `data\accounts\users\<账号ID>.db`。旧版 `data\studypilot.db` 原样保留，需按下文导入。默认只监听 `127.0.0.1`，用于本机运行。

若端口已占用：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.port 8502
```

此时打开 [http://localhost:8502](http://localhost:8502)。

`.streamlit/config.toml` 允许 8501／8502 的 `127.0.0.1` 和 `localhost` 来源发送 Streamlit 原生主题消息。更换其它端口时，在 `client.allowedOrigins` 添加对应的精确本地来源（例如 `http://127.0.0.1:8503`），再刷新浏览器，以确保原生图表和表格也同步换色。请一并保留此配置文件。

## 第一次使用：只做四件事

先注册账号、保存恢复码并登录。默认用户导航为“学习概览、学习档案、学习任务、学习计划、学习记录、账号设置、AI 助手”；普通账号不能看到或访问开发进度。

1. 打开“学习档案”，检查 8 小时及周末设备默认值，勾选确认并保存。
2. 打开“学习任务”，创建“写一个问候程序”，预计 30 分钟，需要电脑。
3. 真正做完学习后，在“学习记录”填写实际学习日期和分钟；在任务页将状态改为“已完成”并确认。
4. 打开“学习概览”，看真实时长和完成率；重启程序确认数据仍存在。

不要一次创建几十个任务。先用一个小任务跑通流程。

## 学习目标由你决定

新档案的学习目标为空。输入框中的浅色文字只是填写示例，既不是输入值，也不会自动保存。每行可以写一个目标，直接修改或删除对应行；清空输入框后，勾选确认并点击“保存档案”，即可删除全部目标。目标可以为空，其余档案仍然能保存。正式目标只有确认保存后才更新；刷新或重新打开网站会从 SQLite 读取已保存内容，未提交的草稿不保证保留。

“AI 帮我制定目标”提供思考提示，并引导你到“AI 助手”讨论。档案表单中的未提交草稿不会自动发送，切换页面可能丢失，请先决定是否保存。助手可以提出档案修改提案；只有下方提案卡片显示的内容被你明确确认后才保存。你也可以忽略提案或返回档案自主编辑。

旧版只在表单确认保存时写入目标，没有记录目标来源。因此不会仅凭“文字与示例相同”删除旧记录，而是在目标区域提示你自行核对；自定义目标和学习记录均保留。新用户的旧默认示例已移到 placeholder，不需要数据迁移。

每位注册用户拥有独立的学习数据库。数据库路径只由验证后的账号 ID 决定，网页不允许用户选择或提交其它账号的 ID。退出时清空整个会话的输入草稿，防止下一个账号看到前一个账号的未保存内容。

## 注册、登录与密码找回

1. 点击“注册账号”，填写 1–64 个字符的用户名，可使用中文、字母、数字、空格和常用符号；首尾空格自动去除，英文不区分大小写，Unicode 等价组合按同一用户名处理，不允许换行、控制字符或不可见格式字符。填写 15–128 字符密码，重复输入密码并确认创建。不要求真实姓名、邮箱、手机或学校账号。旧账号无需迁移。
2. 注册成功会显示一次性恢复码，请妥善保存，再点击“我已妥善保存，去登录”。系统不设置默认账号或默认密码，也不会把首个注册者自动设为开发者。
3. 登录后只显示该账号的档案、任务和记录。点击“退出登录”撤销当前会话；会话最长 12 小时、30 分钟无操作过期。刷新页面、新标签页或程序重启后可能需要重新登录，不提供“记住我”；已保存数据不受影响。
4. 在“账号设置”输入当前密码和两次新密码，确认后更新。全部旧会话与恢复码失效，页面会显示新恢复码。
5. 忘记密码时，在登录页选择“找回密码”，输入用户名、恢复码与两次新密码。恢复码只可使用一次，成功后提供新码并退出所有旧会话。本地版不发送邮件或短信；同时丢失密码和恢复码时无法从网页找回。

登录、注册、找回密码和修改密码提交失败时，会显示错误并保留已填写的字段与确认选项，直接修正后即可重试；成功后清理当前表单。创建任务与记录学习用时同样只在成功保存后重置表单。密码与恢复码草稿只留在当前页面会话中，不作为草稿写入 SQLite；退出或切换账号会清理会话。

密码使用标准库 scrypt（N=2^17、r=8、p=1）与随机盐处理，参数参考 [OWASP Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。数据库保存密码慢哈希、恢复码摘要和会话令牌摘要，不保存这些凭据的明文。连续 5 次凭据失败会阻止该入口对应用户名 60 秒；另有限制连续大量失败的本机全局计数。

## 个人资料与账号设置

账号设置按个人资料、账号与安全、个人数据管理组织，保留 StudyPilot 原有样式。

- 昵称可用中文，1–64 字；可选内置头像标识，填写最多 120 字的个性签名。首次昵称取登录用户名，保存后相互独立；修改个人资料需要勾选确认，旧页面提交会被版本检查拦截。
- “修改登录用户名”需要当前密码和明确确认，新用户名继续使用注册规则并检查重复。修改不搬移个人数据库、不改变开发者角色；当前会话保留，其他会话退出，原恢复码在新用户名下继续有效。
- 登录会话管理列出当前和其他有效会话的登录时间、最近活动；不把浏览器会话当作物理设备。退出其他会话需要确认，不影响当前会话或其他账号。
- JSON 导出仅包含自己的资料、学习档案、任务、真实用时、变更历史、已保存计划及提案审计记录，可供查阅；暂不提供 JSON 一键恢复。完整备份和恢复仍使用本地 `data` 目录。

## 第二阶段：每周规则式学习计划

1. 先在学习档案保存每周预算、每天可用分钟与设备，以及单次学习时长上限。
2. 在任务页填写预计总时长、截止日期、优先级和是否需要电脑。
3. 打开学习计划，选择本周或未来某周，点击“生成计划预览”。一周从周一到周日，只安排今天及以后、且不晚于任务截止日期的日期。
4. 核对日期、分钟、每日容量与未安排原因，勾选确认后保存；同周已有计划时明确确认替换。保存前重新核对档案、任务、真实记录、其他周计划与日期；输入已变化或预览被改动时拒绝提交。
5. 保存后的计划按账号保存在 SQLite；可查看过去周或确认删除某周计划，任务与真实学习记录不会一同删除。真正学习后仍需单独填写真实用时、标记任务状态。

预算按整分钟向下取整。本周已记录用时（包含已删除任务的记录）占用周预算与对应日期容量；任务的剩余时长为预计总时长减去历次真实用时，再减其他周已保存的未来安排，最低为零。不重复分配已完成、已删除或已覆盖预计时长的任务。历史日期的未完成计划不会自动被当作真实学习。

排序先看截止日期，再看任务与科目优先级，同等条件优先照顾电脑任务；普通任务优先使用无电脑日，再按日期分配。这是确定性的贪心规则，不保证全局最优。电脑不可用、截止前时间不足、周预算不足或任务逾期时，会展示尚余分钟和原因；部分安排可以确认保存。已记录用时超过预算时不新增安排，原始真实记录保持原值。

计划只包含日期、任务和分钟段，不推测具体钟点，不包含 AI 建议。修改任务、档案或真实记录后，需要重新生成相关周计划；其他周已保存的未来安排仍作为预留容量，必要时先修改或删除对应周计划。数据库以新增空表方式兼容已有数据，不自动创建档案或示例任务。

## 导入旧版本地学习记录

旧数据不会自动分配给首个注册者。请先注册自己的账号，保持该账号的学习数据为空，停止网站服务，然后在项目目录运行：

```powershell
.\.venv\Scripts\python.exe manage_users.py import-legacy 你的用户名 --server-stopped
```

导入会保留旧目标、任务、时长、变更历史和原数据库文件；若目标账号已保存过任何学习资料，拒绝覆盖。所有表在一个事务内导入，出错全部回滚。不要通过手动删除新记录绕过保护，建议使用一个空账号。导入后重新启动并登录即可读取旧记录。

## 统计口径与历史

- 一周从周一开始，到周日结束；默认日期使用运行电脑的本地日历日期，学习日期由你在表单中选择。
- 本周到期任务完成率 = 本周截止且未删除任务中，当前状态为“已完成”的数量 ÷ 该周任务数量。无到期任务显示“—”，不会把它当成 0%。
- 首页的七天时间与设备来自当前学习档案，是你的可用时间，不是自动生成的任务计划；默认草稿会明确标注。
- 查看过去周的完成率仍采用任务**当前**状态，不宣称是那周结束时的完成率。任务原始变更快照另存于 `task_events`。
- 实际时间按 `study_sessions.study_date` 汇总。任务标记完成不会自动填时间，预计时间也不计入实际时间。
- 科目投入比例只按真实分钟计算。任务修改科目后，旧记录仍使用学习发生时的科目。
- 任务删除采用软删除：从任务列表与完成率分母隐藏，已有时长和变更记录保留。无法从界面撤销任务删除，因此提交前请核对。
- 删除错误的学习记录会移除该记录，统计相应改变。每周历史由 SQLite 中的原始日期记录即时汇总；没有记录的周不等于没有学习。
- 目标目前是文字，尚无可衡量的里程碑，所以不生成“目标完成 60%”这样的数字。

## 开发者查看开发进度

v0.2.0 按账号角色控制，旧的 `STUDYPILOT_DEV_MODE` 环境变量不再授予权限。只有本机维护者可在项目目录为已注册账号授予或撤销角色：

```powershell
.\.venv\Scripts\python.exe manage_users.py grant-developer 你的用户名
.\.venv\Scripts\python.exe manage_users.py revoke-developer 你的用户名
```

角色在下一次页面操作时重新读取；撤销开发者身份后，旧开发页会话回到首页。注册界面、URL 参数和普通账号设置均不能授予开发者权限。其它用户登录同一实例时仍没有开发入口。

当前工作区的启动入口复用了 `work` 环境；如果项目没有 `.venv`，以上命令的 Python 路径可换成 `..\..\work\.venv\Scripts\python.exe`。

## 第三阶段：AI 助手与免费国产模型

实现沿用 OpenAI 兼容的函数调用流程（两家免费服务都提供 `/chat/completions`）：模型返回函数调用，服务端验证白名单和参数，按 call_id 回传结果并继续循环。只使用 Python 标准库 HTTPS，不需额外安装 SDK。适配器位于 `studypilot/ai.py`：主模型智谱 GLM-4.7-Flash，备用模型硅基流动 Xing4.0-29B。两个 Base URL 和模型名写死在代码里，环境变量只能提供密钥；浏览器、对话内容和模型输出都不能指定端点，也不会因为配置而切到收费模型。

在本机 PowerShell 中输入 Key，并在同一终端启动服务；不要把真实 Key 发到聊天中：

```powershell
$zhipuKey = Read-Host "智谱 API Key" -AsSecureString
$env:ZHIPU_API_KEY = ([System.Net.NetworkCredential]::new("", $zhipuKey)).Password
$siliconKey = Read-Host "硅基流动 API Key（可留空，只留主模型也能用）" -AsSecureString
$env:SILICONFLOW_API_KEY = ([System.Net.NetworkCredential]::new("", $siliconKey)).Password
.\.venv\Scripts\python.exe -m streamlit run app.py
```

若旧服务仍在运行，先按 Ctrl+C 停止再启动。界面只提示是否检测到免费模型密钥，不显示它；配置存在不代表已验证额度或网络。不自动加载 `.env`，也不支持自定义 API 端点或模型。Key 留在服务进程环境中，不写入账号库、提案、模型上下文或导出文件；不要在学习问题和备注中主动填写凭据。

进入 AI 助手，选择对话模式、填写问题，并同意本次向免费模型服务发送问题、当前对话及工具读取的学习数据，再点击发送。例如：“看看我本周的学习情况”“把任务 #1 的截止日期改到下周一，先给我看提案”。联网只消耗这两家的免费额度。只读请求不会修改学习资料；修改请求只生成提案，聊天中输入“确认”不会执行。

| 类别 | 工具 |
|---|---|
| 只读 | get_study_profile、list_tasks、get_task、get_study_records、get_progress、preview_weekly_plan |
| 修改提案 | propose_task_create、propose_task_update、propose_task_delete、propose_profile_update、propose_study_record、propose_weekly_plan |

核对提案的完整内容或前后差异后，勾选确认并点击“确认执行”；也可忽略。任务删除保留历史真实用时。记录学习需要额外明确确认确实发生，计划和完成状态不会自动变成真实时长。计划由服务器规则生成，确认时重新核对输入，模型不能提交自编时间表。

每项提案 30 分钟有效，最多 20 项未过期待审提案。执行时重新验证当前账号和数据版本；旧提案遇到资料变化会被拒绝，需要重新生成。业务修改和执行收据在同一 SQLite 事务中提交，重复点击返回原收据。模型没有执行入口。提案与收据重启后保留；对话仅保留在当前页面会话，刷新或退出后清除。清空对话不执行或删除提案。

每次对话最多 6 轮模型请求、12 次工具调用；每次 HTTP 超时不超过 20 秒，循环在下一轮检查 80 秒总期限。查询分页、响应与上下文均有限制，不自动重试。请求固定 stream=false；不对服务提供方的数据处理或保留政策作额外承诺。超时或失败保留问题草稿和已生成的待审提案，不自动执行。

本机当前未配置真实 Key，协议转换、故障切换、工具和确认流程全部用离线可控响应验证；真实联网、免费额度与两家的函数调用兼容性尚未实测，首次配置后请先用只读问题确认。

不要把真实 Key 写进源代码、截图或 Git 仓库。`.env.example` 仅解释变量名。若要清除当前会话 Key：

```powershell
Remove-Item Env:ZHIPU_API_KEY -ErrorAction SilentlyContinue
Remove-Item Env:SILICONFLOW_API_KEY -ErrorAction SilentlyContinue
```

## 免费额度与故障恢复

- 调用顺序固定：先智谱 GLM-4.7-Flash；遇到限流（429）、超时、连接失败或服务端错误，再试硅基流动 Xing4.0-29B。切换后后续工具轮次留在备用服务；认证、参数或响应格式错误直接拒绝，不切换。没有第三家或收费服务兜底。
- 请求是非流式的：整段响应返回后才发给界面，所以不存在“流式输出已开始后切换模型”。
- 两家都失败时返回一句可读提示（只含失败类型，不含上游原文），不写入任何学习数据；已生成的待审提案仍在。
- 服务端持久化限流与全站配额：默认每账号 15 次 / 10 分钟、全站 400 次 / UTC 日，可用 STUDYPILOT_AI_USER_LIMIT、STUDYPILOT_AI_WINDOW_SECONDS、STUDYPILOT_AI_SITE_LIMIT 调整。计数存在账号库（云端为 sp_auth schema），重启不清零；超限返回 429，前端只看到提示，不会重试。
- 日志只写服务商、模型名、结果类型、状态码和毫秒耗时（logger 名 studypilot.ai），不写提示词、学习资料或密钥。

## 三种对话模式

| 模式 | 用途 | 可用工具 |
|---|---|---|
| chat | 日常问答与任意允许的修改 | 全部只读与提案工具 |
| goal_coach | 只讨论学习目标与优先级 | get_study_profile、get_progress、preview_weekly_plan、propose_profile_update |
| plan_builder | 按服务器规则构建每周计划 | 只读工具 + preview_weekly_plan、propose_weekly_plan、propose_task_create、propose_task_update |

模式只缩小可用工具范围，不改变写入规则：三种模式都只能生成待确认提案。工具参数仍要在服务端通过白名单、JSON Schema 和业务校验（如 StudyProfile/TaskInput），非法输出被拒并回传给模型修正。学习档案和用户自定义目标不会被读或写以外的任何途径改动。

## 数据位置、备份与隐私

只需用户名、密码与学习资料，不接入学校账号，不要求姓名、学校、出生日期、联系方式或住址。学习数据本身仍是本地明文 SQLite；登录只控制应用内访问，无法阻止有本机文件访问权限的人读取文件。当前保持本机监听，未配置公网 HTTPS、邮件服务或外部身份供应商。

可选自定义数据库位置：

```powershell
$env:STUDYPILOT_AUTH_DIR = "C:\你的目录\StudyPilot-data\accounts"
.\.venv\Scripts\python.exe -m streamlit run app.py
```

`STUDYPILOT_AUTH_DIR` 指定整个账号目录。`STUDYPILOT_DB` 现在仅指定旧学习数据库的导入来源；未设置账号目录时，默认使用该旧文件所在目录的 `accounts` 子目录。管理命令与应用使用相同环境变量。

先 `Ctrl+C` 停止服务，再复制整个 `data` 目录（包含账号库、每个账号的学习库和旧版库）备份；自定义账号目录时也一同备份。恢复时先停服务，再替换对应文件，不要用空数据库覆盖。更高版本数据库会被拒绝打开，不会自动重置。

建空表属于首次启动的必要初始化；用户档案、任务和学习记录都不会自动写入。模型只能保存待审提案元数据；业务写入的 `confirmed=True` 由独立用户确认入口提供，不能由模型工具参数指定。
